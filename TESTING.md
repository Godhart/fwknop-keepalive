# Проверки SPA Keepalive 0.3.0

В среде подготовки выполнены: **56 тестов Python/CLI/Java прошли, 1 пропущен**
(внешний fwknop-client не установлен); компиляция Python прошла.
Собраны debug APK для трёх ABI и AndroidTest APK, Android Lint — без ошибок.
Инструментальные тесты на устройстве, новый QR через камеру, GUI с дисплеем
и длительная работа нескольких профилей здесь **не выполнялись**.

## Автоматические проверки на Linux

Нужны Python 3.10+, GCC, JDK 17, bash, coreutils и util-linux.

```bash
pip install -r tools/requirements-vault.txt pytest pexpect
python -m pytest -q tests
python -m compileall -q tools
# Дополнительная интеграция с установленным fwknop:
FWKNOP_TEST_BINARY="$(command -v fwknop)" python -m pytest -q tests
```

Если переменная FWKNOP_TEST_BINARY не задана, тест реального CLI пропускается.
Если ansible-vault отсутствует в PATH, интеграционные vault-тесты пропускаются.
Для теста совместимости шифрования требуется Java с модулем jdk.compiler.

Проверяются:
- Валидация YAML/JSON, порты, ключи, интервалы, дубли и неизвестные поля;
  защита fwknoprc от внедрения строк, права файлов и запрет перезаписи.
- Генерация ключей, new/rekey, сохранение исходника, обновление открытого и
  зашифрованного Ansible Vault 1.1/1.2, резервные копии, ошибочные пароли.
- libfko из включённых C-исходников: создание и расшифровка пакета, username,
  доступ, timeout, случайность повторных пакетов, неверный HMAC и повреждения.
- AES-GCM экспорт/импорт, случайность соли/nonce, неверный пароль, подмена
  ciphertext/nonce/salt и неподдерживаемые параметры, границы длины пароля.
- Совместимость Python → настоящий Java ProfileCrypto с Unicode-паролем.
- Bash через PTY: запрос пароля, один пакет по умолчанию, повторения --loop,
  Ctrl+C, удаление rc, отсутствие отправок с неверным паролем или без терминала.
  В этих тестах fwknop заменён контролируемой заглушкой.

## Сборка Android

```bash
cd android
./gradlew :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
```

GitHub Actions выполняет Linux-тесты с fwknop-client, собирает приложение и
инструментальные тесты, запускает lint и сохраняет debug APK как artifact.
Сборка AndroidTest APK **не означает выполнение тестов на устройстве**.

## Инструментальные тесты Android

Используйте отдельный эмулятор или тестовую установку: эти тесты очищают
сохранённые профили приложения. Нужен разблокированный экран, Android API 26+.

```bash
cd android
./gradlew :app:connectedDebugAndroidTest
```

ProfileDeviceTest проверяет реальный Android Keystore, миграцию старой записи,
сохранение нескольких профилей, независимое удаление и ограничение 16 профилей.
UDP-пакеты отправляются только на loopback: два профиля должны отправить пакет,
затем первый останавливается, а второй отправляет следующий через свой период.
После остановки всех сессий оба должны стать неактивными.
Тесты не требуют настоящего сервера и не подтверждают принятие SPA fwknopd.

## Ручная проверка новой версии

1. Сохранить экспорт прежнего профиля; остановить старый сервис. Установить APK
   поверх старого с той же подписью, проверить автоматический перенос профиля.
2. Создать защищённый экспорт с --protect. Проверить импорт QR и JSON:
   неправильный пароль не добавляет профиль; правильный показывает подтверждение;
   отмена не сохраняет данные. Проверить пароль с кириллицей.
3. Проверить импорт старого открытого QR без запроса пароля.
4. Добавить два разных профиля, запустить оба. На серверах проверить индивидуальные
   интервалы и реальные разрешения. Названия могут совпадать — ID должны отличаться.
5. Остановить/удалить один: второй продолжает отправлять. Импорт третьего не
   останавливает первый/второй и сам по себе не отправляет пакет.
6. Проверить общую кнопку остановки в приложении и уведомлении.
7. Перезапустить приложение: список сохранён, работающий сервис продолжает работу.
   После force-stop или перезагрузки все требуют ручного старта.
8. Выключить экран; проверить несколько профилей в фоне и расход батареи.
   Для Doze: adb shell dumpsys deviceidle force-idle, затем unforce.
9. Переключить Wi-Fi → мобильная сеть, отключить сеть на несколько периодов,
   проверить возобновление и серверные таймауты. Успех UDP send не равен
   подтверждению авторизации.
10. Проверить GUI: защищённый экспорт, чтение защищённого JSON, обновление vault.
    Кнопка сохранения YAML пишет открытый текст редактора.

В версии 0.2.1 владелец подтвердил работоспособность APK и bash, стабильную
длительную фоновую работу и отсутствие существенного расхода батареи.
Эти наблюдения не заменяют проверку новых функций 0.3.0 на устройстве.
