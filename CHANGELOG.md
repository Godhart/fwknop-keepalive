# Changelog

## 0.4.0 — 2026-11-08

- Первый iOS-клиент (iOS 16+): SwiftUI, QR/JSON, совместимое шифрование v2, Keychain.
- До 16 профилей; ручная отправка, циклы только на переднем плане, SPA → HTTPS-сайт.
- Проект XcodeGen, XCTest с Python fixture и GitHub Actions на macOS.
- iOS-конфигурация общей libfko использует системный arc4random без временного fallback.
- Android и Python сохраняют функциональную версию 0.3.0; wire-форматы не изменены.


## 0.3.0 — 2026-11-08

- Опция `generate --protect` и переключатель GUI: AES-256-GCM для JSON, QR и bash.
- Пароль при импорте Android, чтении защищённого файла в Python и запуске bash.
- Bash: один пакет по умолчанию; повторение только с `--loop`.
- Android: до 16 профилей, независимые циклы и статусы, остановка одного/всех.
- Импорт JSON-файла; автоматическая миграция прежнего локального профиля.
- Тесты совместимости Python/Java, повреждения данных, терминального ввода и очистки rc.


## 0.2.0 — 2026-11-05

- Настраиваемые длины случайных секретов: `--key-bytes`, `--hmac-key-bytes`.
- Команда `rekey` создаёт новый профиль с новой парой SPA-ключей.
- GUI создаёт ключи для нового профиля, позволяет выбирать длины и заменять ключи.
- `update-vault`: совместимость с fwknop-spa-ansible 0.7.1, обновление двух
  секретов в YAML или зашифрованном Ansible Vault, резервная копия, атомарная
  запись, сохранение комментариев и других переменных. Аналогичная кнопка GUI.
- Проверки реального шифрования/расшифровки Ansible Vault, ошибок и повторных операций.


## 0.1.0 — 2026-11-05

Первый выпуск исходников: Android foreground service, импорт QR, хранение через
Android Keystore, встроенная libfko 2.6.11; Python CLI и CustomTkinter GUI;
общая JSON Schema; генерация QR и bash-цикла; проверки протокола и CLI на Linux.
Android APK и испытания на устройстве в этот выпуск не входят.
